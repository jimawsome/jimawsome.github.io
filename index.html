Selected work

The Upgrade Whisperer

Kubernetes and addon upgrades · every EKS generation · PodDisruptionBudgets

Scope. Kubernetes and platform addon upgrades, automated for every cluster across three EKS generations and four environments.

Problem. Upgrade pipelines on 89 production clusters stalled for hours when disruption budgets blocked node drain or worker nodes went stale.

Decision. Detect the stall early and recover inside the pipeline, rather than paging a human or forcing evictions: drain only what the budgets allow, replace stale nodes automatically, and stop if anything looks unknown.

Result. Affected runs went from 1 to 2 hours to 30 to 40 minutes, worth up to 240 engineering hours per upgrade campaign.

One operations platform instead of a 15-step runbook

Python · MCP server · GitHub Actions

Problem. Every upgrade and audit was a manual runbook that differed by platform generation, and only a few people could run it.

Decision. Build one CLI, MCP server, and CI workflow with safety gates that refuse to upgrade when nodes lag the control plane or when auth, dashboard, or GitOps components are unhealthy.

Result. Fleet-wide audits dropped from 5+ hours to about 2 minutes, and the SRE team now runs the fleet on it.

Patching before it pages

Vulnerability remediation · Wiz · IAM and workload identity

Remediated critical and high vulnerabilities across the fleet, and worked down the medium and low findings alongside them so they never grew into the next critical. Built the security baseline underneath: EKS Access Entries, IRSA, IMDSv2, and KMS.

Finishing a fleet migration before the deadline cost money

EKS · Amazon Linux 2023 · GPU node images

Problem. 90 clusters were on an aging node image and Terraform module, heading into paid extended support.

Decision. Sequence a four-major-version module migration with the AL2023 node image move, including NVIDIA GPU node groups with drivers baked into the image and GPU taints preserved, promoted through test, dev, staging, and production.

Result. Upgrades finished before standard support ended, avoiding $394,200 in annualized premium support exposure.

Fixing the system, not the symptom

Root cause analysis · Karpenter · Network policy

Health checks failing about 90% of the time on a shared cluster traced to the autoscaler choosing undersized spot instances; fixed with a capacity safeguard scoped to that cluster only. A two-hour Terraform retry loop replaced with a 10-second pre-flight check. A security scan that had silently failed for three months, restored.
